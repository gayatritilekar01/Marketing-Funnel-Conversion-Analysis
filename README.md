# Marketing Funnel & Conversion Performance Analysis

**Future Interns – Data Science & Analytics Task 3**

## About the Project

In this project, I worked on marketing and customer conversion data using Power BI.

The main aim of this project was to understand how many customers were contacted, how many of them converted, and which contact channels performed better.

## What I Did

- Cleaned and prepared the data
- Created a marketing conversion funnel
- Calculated the overall conversion rate
- Compared conversions by contact channel
- Compared conversion rates across contact channels
- Checked monthly conversion performance
- Created an interactive Power BI dashboard

## Dashboard Results

- **Total Contacts:** 45K
- **Converted Customers:** 5K
- **Not Converted:** 40K
- **Conversion Rate:** 11.70%

## Key Insights

- Out of around 45K contacts, around 5K customers were converted.
- The overall conversion rate is 11.70%.
- The cellular contact channel brought the highest number of conversions.
- Conversion performance is different for different contact channels.
- The number of conversions also changes from month to month.
- A large number of customers did not convert, showing that there is scope to improve the marketing process.

## Recommendations

- Focus more on contact channels that give better results.
- Improve follow-up with customers who do not convert.
- Study which months and campaigns perform better.
- Try to understand why customers are not converting.
- Use the analysis to improve future marketing campaigns.
